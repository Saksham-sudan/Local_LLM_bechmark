-Grading Layer

-The Metrics to grade will be:
--TTTFT(Total Time To First Token) prefill phase: This metric measures the total time it took for the model pre token generation computing measures in ms.
--TPS(Time Per Token) decode phase: This metric tells us how many token were used by the model per second in decode phase.
--Total Response Latency: This metric tells us about the total time it took for the request to be processed, decoded and sent back with answer including all the overhead measured in seconds.
--VRam Usage: This metric tells us how much memory each prompt took for the model to process.
--ans_qual: This metric checks the quality of each answer.
